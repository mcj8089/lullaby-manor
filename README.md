# Lullaby Manor

**在线体验 / Play online:** https://pipygames.com/games/lullaby-manor-j4n7

Lullaby Manor is an atmospheric mystery puzzle game. Explore the old manor, search for clues, uncover hidden secrets and reveal the truth behind the strange lullaby.

## 技术栈 · Tech stack

- 引擎 / Engine: **Three.js**
- 其他 / Also: WebGL 渲染；Canvas 2D 图层
- 语言 / Language: 中文 + English
- 部署 / Hosting: 纯静态，index.html 即入口，直接丢到任意静态空间即可
