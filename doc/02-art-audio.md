# 夜曲庄园 — 美术与音频方向

本文记录《夜曲庄园》的视觉语言、场景构成、角色与怪物设计、UI 风格，以及全部音频的生成方式。所有素材均为本作原创，没有抓取或复用参考游戏的任何资源。

---

## 1. 视觉方向

**关键词：** 纸片立体书、羊毛毡、夜灯、微缩舞台、温柔惊悚。

- **舞台感：** 每关是一间被「折叠」出来的小房间，地板与墙像厚纸板，家具像剪纸与毛毡拼贴。镜头固定为俯视 3/4 等距视角，玩家像在看一本会动的立体书。
- **光线：** 主光为暖色（纸灯、烛光、月光），阴影柔和；环境光偏冷青，形成「暖灯 vs 冷夜」的对比。所有梦境的雾色与主色不同，但共享同一种舞台布光逻辑。
- **轮廓优先：** 敌人、记忆、门、能力特效都靠形状和发光区分，不依赖颜色唯一编码。移动端缩到 390px 仍能读懂。
- **留白与密度：** 地板中央保留可读的行走空间；装饰集中在家具、墙面与边缘，不遮挡威胁。
- **不做的：** 写实材质、血腥、闪烁频闪、突然贴脸的 Jump Scare。

## 3. 3D 场景构成

每个房间由程序化几何搭建（`src/art/props.js`），不依赖外部 3D 模型，加载快且可离线。基础结构包括：

- **房间壳：** 厚地板、三面矮墙、门框、踢脚线、纸边高光；墙顶做出纸张厚度。
- **相机：** FOV 42，常规高度 15.5、后退 11.5；跟随玩家但夹紧在 ±2.1 / ±0.9 范围内，避免镜头晃动。窄屏（手机）自动拉高到 17.4 / 13.8，并放宽夹紧范围，保证房间完整入画。菜单使用 18 / 14 的更远景。
- **光照：** 半球光 + 柔环境光 + 暖主光（2048 阴影贴图）+ 冷轮廓光 + 一盏跟随场景的暖点光。ACES Filmic 色调映射，曝光 1.38。
- **空气感：** 每间房有漂浮尘埃粒子、雾、局部光晕 sprite；Boss 房额外有玫瑰色逆光与蛛网。

### 3.1 各梦境的专属陈设

| 梦境 | 墙面与家具 | 动态细节 |
| --- | --- | --- |
| Nursery | 两张歪挂的儿童画、11 颗星星彩旗、旋转八音盒挂饰（四色小星）、纸箱与积木 | 挂饰缓慢旋转；地板响板会发光 |
| Study | 顶天书架与程序化书脊纹理、烛台与暖点光、旧相框、浸水的地板 | 水面上下呼吸、反射光斑；潮位变化 |
| Garden | 木格藤架与 20 片叶子、两只陶盆植栽、歪斜的紫色相框、荆棘 | 藤蔓轻微摆动；荆棘门有呼吸式脉动 |
| Attic | 三根木梁与横梁、裸灯泡与电线、倾斜相框、齿轮与箱子 | 灯泡微晃；摆锤按正弦节奏扫动 |
| Gallery | 多组镜框、红绳围栏、冷蓝聚光、悬挂画框 | 镜面反射微光；镜影从镜框旁浮现 |
| Weaver | 巨型蛛网、四个缠满布条的茧、玫瑰色逆光、线轴与针 | 蛛网轻颤；线束旋转；地刺预警 |

### 3.2 可交互物件

- **记忆：** 每场梦不同造型（音符、书页、月骨、齿轮、镜片、黎明尘），悬浮、自转、带柔光与拾取粒子。
- **出口门：** 拱门 + 门缝光；集齐 3 段记忆后由暗转亮，门缝溢出对应梦境色。
- **响地板（Nursery）：** 三块松动木板，踩上快速跑过会发出 11.5 米噪音。
- **荆棘门（Garden）：** 交错的藤条与尖刺，封住碰撞体，只能被口哨打开。
- **镜框（Gallery）：** 装饰性镜面，营造视觉迷宫；镜影在附近出生。
- **摆锤（Attic）：** 锚点 + 摆杆 + 摆锤，按固定正弦节奏造成伤害。
- **黎明尘（Boss）：** 金色发光种子，场上最多 3 个，拾取后 2.6 秒重生。

## 4. 角色

### 4.1 June（玩家）

一盏会走路的小灯：暖白发光核心、纸片状的身体、飘动的围巾状光尾。使用自定义 GLSL 果冻材质做呼吸与挤压拉伸，移动时轻微倾斜，停下时缓慢起伏。她是画面中唯一的纯暖白光源，保证在六种配色里都能被一眼找到。

### 4.2 家人

| 角色 | 立绘 | 守护星造型 | 性格线索 |
| --- | --- | --- | --- |
| Ollie | 抱玩偶的小男孩，困倦 | 八角星 | 怕黑，但会学你勇敢 |
| Theo | 戴眼镜的父亲，衬衫皱褶 | 纸飞机 | 工作没做完，话也没说完 |
| Biscuit | 垂耳小狗，戴旧项圈 | 骨头 | 只认回家的路 |
| Clara | 母亲，披肩与发髻 | 齿轮 | 总把自己的时间借给别人 |
| June | 少女，提灯 | 镜片 | 面对另一个自己 |

每位家人救回后化为对应造型的小挂饰，围绕玩家缓慢公转；受击时碎裂成同色粒子。

### 4.3 噩梦

| 敌人 | 轮廓 | 行为读法 |
| --- | --- | --- |
| Hushling 噤声灵 | 圆滚滚的黑色毛球，两只大耳朵，白点眼 | 听到声音就转向；耳朵先竖起，再扑过来 |
| Ink Eel 墨鳗 | 细长墨色鱼体，发光眼；水下只剩影子 | 潮水上涨时浮出；水面先起波纹 |
| Thorn Hound 荆棘猎犬 | 低伏的枝条犬，背脊带刺 | 压低身体 = 即将冲锋；0.55 秒前摇 |
| Cuckoo Sentinel 布谷哨兵 | 木壳钟鸟，齿轮外露 | 每 0.45–1.35 秒停顿、抬头、直线冲刺 |

所有敌人都有「预警 → 行动 → 恢复」三段节奏，给玩家 0.5 秒以上的反应窗口。

## 5. 特效与材质

- **纸张 / 毛毡：** 程序化 Canvas 纹理生成纸纤维、木纹、书脊、蛛网与噪点，避免外部贴图。
- **果冻 GLSL：** 用于 June 与部分记忆，顶点做低频挤压，片元做边缘柔光与内部透光。
- **粒子：** 拾取火花、守护星碎裂、能力脉冲、Boss 线束、地刺喷发、黎明 flare 尾迹，全部为轻量 sprite/instanced 粒子。
- **屏幕反馈：** 受伤红闪、镜头轻震、拾取金色闪光、门开启的呼吸光。
- **性能取舍：** 阴影只保留一盏主光；粒子有上限；Boss 线束使用线段几何而非真实光束网格；移动端像素比上限 2。

## 6. UI 与平面

- **开屏：** 深色纸纹背景、居中徽章、`pipygames.com`、健康游戏忠告、分段式加载条与阶段文案（点灯 → 折纸墙 → 调音 → 庄园苏醒）。
- **HUD：** 左上灯心与守护星，中上记忆计数，右下能力圆钮（名称 + 按键 + 冷却环），右上暂停/声音。窄屏自动缩小并改为触屏布局。
- **菜单：** 五张梦境卡（AI 生成的场景插画）+ 家人立绘 + 星级/进度；Boss 卡在集齐五梦后点亮。
- **结算：** 星级三连、时间/par、救援角色卡、下一关与分享。
- **分享卡：** 1080×1080，深色纸面 + 金色描边 + 徽章 + 梦境数 + 星星 + 玩家署名 + `#LullabyManor`；无第三方 Logo。

## 8. 音频

全部音频由 `tools/gen_audio.py` 用 numpy 从振荡器与滤波噪声合成，采样率 22050 Hz，输出 WAV。没有采样包、没有第三方音乐。

### 8.2 音乐（4）

| 文件 | 时长 | BPM | 配器与情绪 |
| --- | --- | --- | --- |
| `bgm-menu.wav` | 30.0s | 72 | 八音盒、暖 pad、低音；温柔但有一点不安 |
| `bgm-dream.wav` | 34.3s | 84 | 拨弦、八音盒动机、轻刷；循环探索感 |
| `bgm-boss.wav` | 32.7s | 132 | 低音脉冲、钟表滴答、合唱 pad、失真八音盒；压迫感 |
| `bgm-ending.wav` | 29.1s | 66 | 明亮 pad、八音盒旋律、钟声；黎明与释然 |

音乐循环通过交叉淡入淡出（1.1 秒）衔接；暂停时音乐降到 35%，广告播放时静音。音效与音乐音量分别由 `audio.sfxVolume = 0.62`、`musicVolume = 0.42` 控制，玩家可一键静音（存档记忆）。

### 8.3 声音设计原则

- **可读性优先：** 每种威胁有独立音色（猎犬的低吠、哨兵的齿轮、镜影的玻璃泛音），闭眼也能分辨。
- **不刺耳：** 无高频尖啸；受伤音短促但不惊吓。
- **音乐让位：** 关键音效（拾取、受伤、能力）在中频留出空位。
- **无版权风险：** 所有波形在构建时生成，仓库内即为最终 WAV。

## 9. 资产再生成

```bash
python tools/prep_images.py   # 重新处理图片母版
python tools/gen_audio.py     # 重新合成 15 SFX + 4 BGM
```

两个脚本都只依赖 Python + Pillow / numpy，不访问网络。生成后重新执行 `python tools/build_web.py` 即可把新素材打进单文件版。
