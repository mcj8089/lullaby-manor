## 1. 一句话概念

午夜，阁楼的八音盒自己响了起来。一家人沉在五个不同的噩梦里。你是最小的女儿 June，提着一盏灯醒来——钻进每场梦，找回三段记忆，牵回家人，在天亮前爬上阁楼。

**Elevator pitch：** 一款纸片立体书风格的 3D 梦境救援游戏。每场梦改写一条规则，也送你一个新动词；你救回的每个家人，都会变成替你挡下一击的守护星。

---

## 2. 设计支柱

1. **每场梦一条新规则。** 声音、潮水、荆棘、时间、镜影——不是换色，而是换玩法动词（静步、平息、吹开、倒带、换位）。
2. **救援即成长。** 救回的家人不只是剧情数字，它们真的围在你身边，各挡一次伤害；叙事与机制同源。
3. **看得懂的恐惧。** 诡异但不血腥；敌人有明确的前摇、音效与轮廓，失败来自判断而不是突袭。
4. **一分钟进入游戏。** 开屏只做三件事：品牌、健康忠告、加载进度；点击一次即可进入。无账号、无体力、无强制教程长文。
5. **手工关卡 + 明确星级。** 16 关全部手写布局；三星规则一眼可懂，重复挑战有意义。

---

## 3. 目标受众与使用场景

- **年龄：** 9 岁以上；惊悚可爱（spooky-cute），无血腥、无 Jump Scare。
- **人群：** 喜欢《Cursed Dreams》《Little Nightmares》氛围但不想被吓到、喜欢 Monument Valley 式美术的休闲与中度玩家；也适合万圣节节点投放。
- **单局时长：** 1.5–2.5 分钟一关；完整流程约 35–50 分钟，熟练玩家约 20 分钟。
- **设备：** 1280×720 桌面为主，兼容 390×844 竖屏手机；键盘 + 触屏摇杆双方案。
- **语言：** 英文默认；中文仅通过 URL 参数切换，游戏内没有语言按钮。

---

## 4. 核心循环

### 4.1 瞬间循环（1–10 秒）

观察巡逻 → 选择「跑」或「踮脚」→ 绕过/定住噩梦 → 吃记忆 → 找下一个目标。

### 4.2 关卡循环（90–155 秒）

进入梦境 → 收集 3 段记忆 → 门苏醒 → 穿过门 → 结算星级与救援进度。

### 4.3 整轮循环（约 35–50 分钟）

三关一场梦 → 第 3/6/9/12/15 关救回一位家人 → 五位家人集齐 → 阁楼开启 → 织梦者 Boss → 黎明结局。

### 4.4 元循环

星星、最佳时间、关卡解锁、家人收集、玩家署名与分享卡。没有金币、没有商店、没有付费墙。

## 5. 玩家与伤害模型

| 参数 | 数值 | 说明 |
| --- | --- | --- |
| 生命 | 3 颗灯心 | 每次受伤 -1 |
| 无敌帧 | 1.25 秒 | 受伤后短暂闪烁 |
| 击退 | 4.2 | 把玩家推离伤害源 |
| 移动速度 | 3.6 | 奔跑 |
| 潜行速度 | 1.75 | 按住 Shift / 触屏 TIPTOE |
| 加速度 / 摩擦 | 18 / 14 | 轻微惯性，便于微调走位 |

**守护星：** 每位已救回的家人（以及广告祝福）在每关开始时环绕玩家，各吸收一次伤害。守护星破碎不计入「掉血」，因此仍可拿三星。守护星先用完，才会扣灯心。

**失败：** 灯心归零即本关失败。可立即重试，不扣资源；若广告开启，可看一次激励广告带 1 颗灯心复活（每轮限一次）。

## 6. 记忆、出口与星级

- 每关固定 3 段记忆，收集齐后出口门亮起；门未开时靠近会提示还差几段。
- 记忆在关卡内不因受伤而丢失；失败重开则重置。
- **星级：** 通关 1 星；全程未掉灯心 +1 星；用时 ≤ 关卡 par 时间 +1 星。
- 三星不要求「不用能力」，鼓励玩家大胆使用技能。
- 最佳时间与最高星级分别存档；重玩只升不降。

每关 par 时间随梦境与复杂度递增：90 秒（第 1 关）到 155 秒（第 15 关），Boss 为 240 秒。

## 9. 布局与关卡语法

- 每张地图 11 × 8 格，格宽 1.7 世界单位；俯视，上为北。房间约 18.7 × 13.6 单位。
- 地图字符：`.` 地板，`#` 家具/墙，`P` 出生点，`X` 出口，`N` 记忆，`E` 噩梦，`C` 响地板（育婴室），`G` 荆棘门（花园），`M` 镜框（画廊），`S` 镜影出生点（画廊），`^` 摆锤锚点（阁楼）。
- 每关 3 个 `N`、1 个 `P`、1 个 `X`；`#` 使用对应梦境的家具族，避免「同一种墙换颜色」。
- 布局原则：入口 2–3 秒内看到第一段记忆；出口不放在出生视线正前方；至少一条「安全但不直接」的路线与一条「冒险但快」的路线。
- 难度曲线：第 1 关零失败压力；第 2 关引入能力解法；第 3 关首次要求「先清威胁再拿记忆」；此后每场梦重复「引入 → 加压 → 救家人」三段式。

## 10. Boss：织梦者 The Weaver

### 10.1 幻想

八音盒的看守者，一只由线、针与旧玩具缝成的巨大蜘蛛。它不是要杀你，而是要把 June 也缝进梦里。战斗是「把黎明带回阁楼」，不是射击。

### 10.2 数值

| 参数 | 数值 |
| --- | --- |
| 生命 | 100 |
| 单次黎明 flare 伤害 | 20（需 5 次） |
| 每次 flare 消耗 | 3 个黎明尘 |
| 场上黎明尘 | 最多 3 个 |
| 黎明尘重生 | 2.6 秒/个 |
| 接触伤害半径 | 1.5 |

### 10.3 循环

1. 场上刷新 3 个黎明尘；玩家在 Boss 的线束与地刺之间穿行拾取。
2. 集满 3 个后，技能键变为「黎明」，按 E 发射一枚追踪 flare，命中扣 20 血。
3. 阶段阈值 66 / 33：
   - **阶段 1「织机苏醒」**：旋转线束 + 地刺预警。
   - **阶段 2「丝线收紧」**：线束数量与转速提升；每 14 秒召唤 2 只噤声灵。
   - **阶段 3「最后的摇篮曲」**：线束更快；每 11 秒召唤 3 只噤声灵。
4. 血量归零 → 织机沉默 → 黎明结局。

Boss 战没有记忆收集；par 240 秒。玩家仍带 3 颗灯心与守护星，失败可立即重试。

## 12. 界面与流程

```
开屏（品牌 / 健康忠告 / 加载条）
  → 进入庄园
    → 主菜单（继续 / 开始 / 五梦境地图 / 玩法 / 故事 / 分享 / 声音）
      → 关卡（HUD：灯心、记忆、守护星、能力 CD、暂停）
        → 通关结算（星级、时间、救援、下一关 / 重玩 / 分享 / 祝福广告位）
        → 失败（复活广告位 / 重试 / 返回）
      → 第 16 关 Boss 开场卡 → Boss 战 → 黎明结局
```

- **HUD 极简：** 左上灯心与守护星，中上记忆进度，右下能力按钮与冷却，右上暂停/声音。
- **触屏：** 左下虚拟摇杆，右下能力按钮，TIPTOE 切换；无悬停依赖。
- **暂停：** P / Esc / 触屏按钮；暂停时音乐降音，不暂停计时？——计时在暂停时冻结，恢复后继续。

## 13. 广告与商业化预留

当前 **全部广告关闭**（`ads.enabled = false`），UI 不出现任何广告入口，游戏完整可玩。

已接线的位置：

| Placement | 类型 | 触发 | 默认限制 |
| --- | --- | --- | --- |
| `revive` | 激励 | 失败后以 1 颗灯心复活 | 每轮 1 次 |
| `guardianBlessing` | 激励 | 通关后下一关 +1 守护星 | 每轮 1 次 |
| `levelClear` | 插屏 | 每 4 关通关后 | 60 秒冷却 |
| `gameOver` | 插屏 | 预留，默认关闭 | 每 3 局 |

开启方式：把 `config/ads.config.js` 与 `src/sdk/sdk.config.js` 的 `enabled` 改为 `true`，设置 `provider`（`mock` / `poki` / `crazygames` / `custom`）与 placement id，重新打包即可。广告播放时自动暂停游戏并静音，结束恢复。

**不做的：** 强制插屏、付费去广告、体力、抽卡、账号。星级与关卡进度永远不卖。

## 14. 分享与裂变

- 通关/失败/结局均可打开分享面板；玩家可填 0–16 字昵称，也可留空。
- 生成 1080×1080 战绩卡：梦境数、星星、用时、昵称、`#LullabyManor`、`pipygames.com`。
- 渠道：Facebook、Reddit（带链接的分享面板）；Instagram、TikTok、YouTube（下载卡片 + 平台内发布提示）；另提供复制邀请文案与系统原生分享（Web Share）。
- 文案强调挑战句「Can you bring them home?」，把成绩变成可比较的炫耀点。
- 分享入口在结算页与菜单，不打断关卡。

---

## 15. 本地化

- 英文默认，简体中文通过 `?lang=zh`（兼容 `?locale=zh` / `zh-CN`）。
- 两种语言各 286 个键；占位符一一对应，构建前做计数校验。
- 游戏内 **没有** 语言切换按钮；语言只由 URL 决定，避免误触与状态分叉。
- 字体使用系统字体栈，不加载外部字体，保证离线与中文覆盖。

## 16. 成功指标（上线后观察）

- **启动：** 开屏 → 菜单转化率；资源加载失败率。
- **教学：** 第 1 关完成率；第 2 关流失点。
- **留存：** 第 3 / 6 / 15 关到达率；Boss 到达率与击杀率。
- **分享：** 分享面板打开率、卡片下载率、各渠道点击。
- **广告（开启后）：** revive 展示/接受率、祝福接受率、插屏对次局留存的影响。
- **技术：** 首屏加载中位数、移动端帧率、WebGL 失败率。

## 18. 验收定义

1. 16 关均可从菜单进入并通关，Boss 可被击败并进入结局。
2. 三星、最佳时间、解锁、家人救援、守护星均正确存档并在刷新后恢复。
3. 中英文切换仅由 URL 控制；两语言无缺失键、无占位符错位。
4. 非授权域名完整加载后显示锁定卡，3 秒后跳转 `https://pipygames.com`。
5. 广告关闭时无任何广告入口；开启 mock 后各位置可完整走完生命周期。
6. 桌面 1280×720 与手机 390×844 均可完成第 1 关；无控制台异常。
7. 单文件 `dist/lullaby-manor.html` 可通过 file:// 与静态服务器两种方式运行。
