## 3. 缺陷记录

### BUG-01（高）Boss 蓄力上限读取了不存在的字段

- **位置：** `src/game/game.js:452`
- **现象：** HUD 显示 `DAWN undefined/3`；未收集黎明微光也能施放灼光；`debugCharge()` 无效。
- **原因：** Boss 配置只有 `chargeCost: 3`，运行时读取 `cfg.maxCharge`，得到 `undefined`。
- **修复：** `maxCharge: cfg.chargeCost`。
- **复测：** 初始 `0/3`；`debugCharge` 后 `3/3`，HUD 显示 `PRESS E`；空充能点击不发射；5 发把 100 HP 打到 0。

### BUG-02（中）通关面板显示字面量 `(n) / 3`，Boss 关显示 0/3 记忆

- **位置：** `index.html:400`、`src/ui/ui.js:142,852`
- **现象：** 每次通关，星星统计下方直接显示 `(n) / 3`；Boss 关明明没有记忆收集物，却显示 `0 / 3`；“New best time”落在“记忆”统计下方，语义不清。
- **修复：**
  - 星星下方改为真实本关星数（如 `3 / 3`），元素 `#win-stars-earned` 在 `showWin()` 时写入。
  - Boss 关记忆数显示 `—`。
  - “New best time”并入时间行：`par 1:30 · New best time`。
- **复测：** 剧情关与 Boss 关均无 `(n) / 3`；390 宽中文面板无裁切。

### BUG-03（低）Facebook 分享提示与真实流程不符

- **位置：** `config/locales.js:247,559`
- **现象：** 旧文案要求用户“下载卡片后附到 Facebook”，但 Facebook 流程只打开分享窗口，不下载卡片。
- **修复：** 改为“已打开 Facebook 分享窗口，发布到动态或小组即可”。
- **复测：** 中英文案占位符仍为 286/286 对齐。

### 环境事件（非代码缺陷）

源码测试初期，8141 端口上残留了两个旧服务器进程，Windows 允许同时监听，导致“源码”请求实际命中了旧 dist，出现修复已存在却复现失败的假象。终止旧进程并改用单一 8151 端口、确认服务端 `game.js` 为 60,198 字节后，全部关键用例重跑通过。

## 4. 未覆盖 / 限制

以下项目**没有**在本次自动化中完成，交付时不应视为已验收：

1. **真人逐关试玩与难度手感：** 数据层验证了 15 关都能完成，但没有按真实操作逐关体验难度曲线、敌人压迫感与 par 时间是否合理。
2. **真实广告平台：** Poki / CrazyGames / 自定义适配器、真实 placement id、真实填充率与超时未测；mock 流程已验证。
3. **真实社媒账号发布：** Facebook / Reddit 只验证分享页打开；Instagram / YouTube / TikTok 只验证卡片下载与提示，未实际登录发布，也未检查平台预览。
4. **白名单外真实跳转：** 授权卡、3 秒倒计时、资源预加载已验证；没有等待浏览器真正导航到 `https://pipygames.com`。
5. **触屏摇杆手势：** 390 宽布局、能力按钮、点击触发已验证；摇杆拖动与多指操作未测。
6. **真机与其它浏览器：** Safari、Firefox、低端 Android 真机未测；SwiftShader 与真实 GPU 的表现可能不同。
7. **45 分钟健康提示的真实计时：** 通过推进 `playSeconds` 强制触发验证；没有真实等待 45 分钟。
8. **音频听感：** 15 SFX + 4 BGM 的加载、切换、静音逻辑已验证；没有进行人工听音与音量平衡评估。
9. **线上部署：** pipygames.com 的 DNS、HTTPS、CDN 缓存与 iframe 策略未在本机验证。

## 5. 复现方式

```bash
cd data/games/lullaby-manor

# 源码版
python tools/start.py                 # http://127.0.0.1:8133/ 与 /?lang=zh

# 单文件版
python tools/build_web.py             # dist/lullaby-manor.html + dist/web/ + zip
```

浏览器手动检查清单：

1. 打开首页，确认开屏网址、健康忠告、进度条，随后进入故事/菜单。
2. 开始第 1 关：收集 3 段记忆 → 门亮 → 进入 → 三星结算。
3. 失败一次 → 重试；在 `config/ads.config.js` 与 `src/sdk/sdk.config.js` 同时开启广告后，确认复活与祝福流程。
4. 通关第 4 关后点“下一场梦”，确认插屏（广告开启时）。
5. 直接进入第 16 关，收集 3 枚黎明微光 → E → 5 发击杀 Boss → “See the dawn” → 结局。
6. 用 `?lang=zh` 重开，检查标题、帮助、关卡名、结算与分享文案。
7. 用非白名单域名访问，确认资源加载完成后出现锁定卡并在 3 秒后跳转。
8. 双击 `dist/lullaby-manor.html`，确认离线可玩。
